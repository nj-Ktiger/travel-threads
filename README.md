# ✈️ Travel Threads Content Generator

AI 기반으로 매일 아침 쓰레드(Threads)에서 바이럴될 만한 **고화질 여행 사진 + 매력적인 꿀팁 텍스트**를 자동 생성하여 텔레그램으로 전송해 주는 자동화 봇입니다.

## 🚀 운영 방식 (3초 컷)
1. 매일 아침 텔레그램 새 봇(@agent_makemoney_bot)으로 고화질 여행지 사진과 쓰레드용 글이 도착합니다.
2. 텔레그램에서 사진을 길게 눌러 갤러리에 저장하고, 아래 본문을 복사합니다.
3. 쓰레드(Threads) 앱을 켜서 사진 1장 첨부 + 본문 붙여넣기 ➔ [게시] 누르면 끝!
4. 쓰레드 프로필에 걸어둔 네이버 여행 블로그로 자연스러운 트래픽 유입을 만듭니다.
